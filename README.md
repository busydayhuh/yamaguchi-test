# YAMAGUCHI Hair Styler

Тестовое задание: адаптивная промо-секция для YAMAGUCHI Hair Styler с desktop-анимацией переключения слайдов.

## Что реализовано

- Адаптивная верстка слайдов под mobile, tablet и desktop.
- Desktop-режим с боковым колесом навигации.
- Переключение слайдов по скроллу мыши.
- Переключение слайдов по клику на иконку в колесе.
- Синхронизация активного слайда и активной иконки.
- Циклическое переключение слайдов в desktop-режиме.
- Анимации реализованы с помощью GSAP.

## Технологии

- HTML
- CSS
- JavaScript
- Vite
- GSAP

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить dev-сервер:

```bash
npm run dev
```

Собрать проект:

```bash
npm run build
```
